# Claude 项目记忆配置

## 项目概述
这是一个 HTML 和 CSS 学习项目，主要用于创建教学用的网页应用。

## 技术栈
- Vue 3
- HTML5
- CSS3
- JavaScript (ES6+)

## 项目结构
```
vuetest/
├── src/
│   ├── pages/
│   │   └── GuidePage.vue    # 指导页面组件
│   └── assets/             # 静态资源
├── public/                 # 公共文件
└── package.json           # 项目依赖
```

## 主要功能
1. **阅读计划生成** - 根据用户输入生成个性化的学习计划
2. **常见问题解答** - 提供编程学习相关的 FAQ
3. **响应式设计** - 适配不同设备屏幕

## 代码规范和约定
- 使用中文注释和变量命名
- 遵循 Vue 3 Composition API 规范
- CSS 采用模块化命名（BEM）
- 保持代码简洁，避免过度工程化

## 用户偏好
- 使用中文进行交流和代码注释
- 偏好渐进式功能开发
- 重视代码可读性和可维护性

## 开发流程
1. 先规划功能需求
2. 设计用户界面原型
3. 实现核心功能
4. 添加样式和交互效果
5. 测试和优化

## 记忆要点
- 项目主要用于教学和学习目的
- 用户是中文使用者，所有界面文字都应使用中文
- 注重用户体验和界面美观
- 代码质量优先于功能数量
